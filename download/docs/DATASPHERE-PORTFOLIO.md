## 🏢 À Propos de DataSphere Innovation

**DataSphere Innovation** est une startup HealthTech guinéenne fondée en 2024 à Conakry, République de Guinée. Nous concevons et développons des solutions technologiques adaptées au contexte des systèmes de santé africains, avec une expertise particulière dans les Systèmes d'Information Hospitaliers (SIH).

Notre conviction : **la technologie peut sauver des vies** lorsqu'elle est conçue avec et pour les professionnels de santé locaux. Chaque ligne de code que nous écrivons a pour but de réduire les temps d'attente, d'améliorer la qualité des soins et de rendre les données de santé accessibles et sécurisées.

## 🏥 HealthFlow Guinea — Notre Produit Phare

### Présentation

**HealthFlow Guinea** est le premier Système d'Information Hospitalier (SIH) intégré conçu spécifiquement pour le contexte guinéen. Développé de zéro par notre équipe à Conakry, il couvre l'ensemble du parcours patient avec 10 modules fonctionnels et 63 modèles de données.

### Les 10 Modules

```
┌─────────────────────────────────────────────────────────┐
│                  HEALTHFLOW GUINEA                       │
│              10 Modules Intégrés                         │
│                                                         │
│  👤 Gestion Patients         💊 Pharmacie & Stock       │
│     QR Code, allergies,         Stocks, lots, alertes   │
│     antécédents                 de pénurie              │
│                                                         │
│  📅 Rendez-vous & Consult.  🏥 Hospitalisation & Urg.  │
│     Agendas, constantes,        Triage 5 couleurs,      │
│     ordonnances                 admissions, lits        │
│                                                         │
│  🔬 Laboratoire             🤰 Maternité & Vaccination │
│     Catalogue, résultats,       Grossesses, accouchem., │
│     validation biologiste       calendrier guinéen      │
│                                                         │
│  💰 Facturation & Paiements 📺 Téléconsultation         │
│     Mobile Money, assurance,    Vidéo, chat, messages   │
│     reçus PDF                   sécurisés               │
│                                                         │
│  📊 Dashboard Santé         🚨 Alertes Santé Publique   │

│                                                         │
```

### Caractéristiques Techniques

| Caractéristique | Détails |
|----------------|---------|
| **Frontend** | Next.js 16, React 19, TypeScript 5, Tailwind CSS 4 |
| **Backend** | Next.js API Routes, Prisma ORM |
| **Base de données** | 63 modèles, PostgreSQL 16 |
| **Authentification** | JWT, RBAC, MFA (TOTP/SMS/Email) |
| **Multi-tenancy** | Isolation par établissement |
| **Paiements** | Mobile Money (Orange, MTN, Celcom) |
| **Triage** | Système français 5 couleurs (ROUGE/ORANGE/JAUNE/VERT/BLEU) |
| **Vaccination** | Calendrier vaccinal guinéen (BCG, DTC, VPO, Rougeole…) |
| **Déploiement** | Docker, Kubernetes, CI/CD GitHub Actions |
| **API** | 17 endpoints REST, documentation complète |
